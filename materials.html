Under the hood

How this library rebuilds itself.

Extraction

Source PDFs — scanned or text-based — are parsed by a layout-aware document model; tables, bold headers and page structure survive the trip.

Compilation

Each lesson is restyled into a clean editorial page with its own design language — consistent typography, chapter-specific accents.

Printing

A headless browser prints every chapter to pixel-perfect A4 — headings, callouts and table rows kept intact at page boundaries.

Indexing

This dashboard re-indexes itself: titles, snippets, web-view and download links are refreshed on every pipeline run automatically.
